# 0625. Draw the interface's icons from Lucide

Status: proposed
Date: 2026-10-19

## Context

The interface drew its icons from Material Design Icons (MDI): a webfont of some
7,400 icons, filled and outlined shapes mixed, compiled in by
[0590](0590-compile-the-bundled-fonts-into-the-executable.md). The approved
mockup draws Lucide, an outline set drawn with round 2-unit strokes on a 24-unit
grid, and the interface is being brought to match it. The sources drew 96
distinct `ICON_MDI_` constants in 52 files.

- Lucide has no brand or language icons: nothing for C, C++, C#, Lua, Python,
  Markdown, PowerShell or Visual Studio.
- Lucide's font, from the `lucide-static` package, has an em of 1000 units, an
  ascent of 1000 and a descent of 0. Each icon's 24-unit square stands on the
  baseline and is one font size tall. ImGui puts a merged font's baseline on the
  face's own, so an unmoved icon sits high beside text by the face's descent,
  about 3 px for Inter at 14 px.
- ImGui scales a merged font's glyph offset with the size it bakes and rounds it
  to a whole pixel. MDI's fixed 1.5 px offset, carried over, left Lucide's icons
  up to 3.5 px above the capitals beside them at 200 %.
- The font's glyph headers give every glyph a box that starts at the baseline
  and at the left edge, whatever it draws. ImGui's glyph box is therefore not
  where the icon is, and only the drawn pixels show its middle.
- Inter has private-use glyphs of its own at 478 of Lucide's codepoints, 44 of
  them icons the interface draws, such as `check`, the chevrons and `folder`.
  ImGui takes a glyph from the first source of a face that has it, and a face's
  own font comes first, so Inter's glyphs would win. JetBrains Mono has the
  Powerline symbols at U+E0A0–U+E0A2 and U+E0B0–U+E0B3, which terminal prompts
  draw; `copy`, at U+E0A2, is the one used icon among them. MDI's codepoints,
  from U+F68C up, met neither.
- The strong face, Inter SemiBold, carried no icons.

## Decision

Draw every icon from Lucide, pinned to `lucide-static` 0.460.0.

- **Files.**
  - `vendor/fonts/lucide.ttf` is
    `https://unpkg.com/lucide-static@0.460.0/font/lucide.ttf`.
  - `vendor/fonts/Lucide-LICENSE.txt` is the same version's `LICENSE` (ISC). Its
    text replaces MDI's in `THIRD_PARTY_NOTICES.txt`, which About shows.
  - `vendor/fonts/IconsLucide.h` holds one `#define ICON_LC_<NAME> "<utf8>"` per
    icon, the name upper-cased with each `-` turned into `_`.
    `scripts/New-IconHeader.ps1` generates it from the same version's
    `font/info.json`. The header and the font always come from one version,
    because a codepoint names a different icon from one version to the next.
  - `Core/src/Core/ImGui/Fonts/Lucide.cpp` is generated by
    `scripts/New-FontData.ps1`, as [0590](0590-compile-the-bundled-fonts-into-the-executable.md)
    says.
  - MDI's header, webfont, licence and generated data are deleted. The premake
    include entry for `vendor/fonts` is `IncludeDir.Icons`.
- **Faces.** Lucide is merged into the interface, the code and the strong face,
  each through `ImFontConfig::DstFont`, so the merge does not depend on the
  order the faces are added.
  - The two Inter faces give up the span from the lowest to the highest used
    icon (`Core::UsedIconSpan()`, through `ImFontConfig::GlyphExcludeRanges`),
    so Lucide draws every used icon there. Inter's private-use glyphs are not
    characters any text needs.
  - JetBrains Mono gives up nothing: its Powerline glyphs stay for the
    terminal. In the code face `copy` therefore draws as the Powerline padlock;
    it is the caption's restore glyph and is drawn in the interface face.
  - Each icon's minimum advance is the face's size, as before.
  - Each face lowers its icons by its own descent: `GlyphOffset.y` is the
    face's size times `-descent / (ascent - descent)`. The share is read from the
    face baked at ImGui's largest size, 512 px, where ImGui's rounding of the
    ascent and descent to whole pixels does not matter.
  - Lowered so, Lucide's square spans the face's line from ascender to
    descender, and an icon centres on the face's capitals. ImGui rounds the
    scaled offset to a whole pixel, so the icon's middle is within a pixel of
    the capitals' middle at every scale. Measured from the drawn pixels, it is
    within half a pixel in all three faces from 100 % to 200 %.
- **Baked set.** `kUsedIcons` lists the 84 Lucide icons the interface draws and
  only these are baked. `Core::UsedIcons()` returns the list for the tests.
  `scripts/Test-IconsLoaded.ps1` fails on any `ICON_LC_` constant missing from
  it and on any `ICON_MDI_` constant at all.
- **Mapping.** Every MDI constant became the Lucide icon below, but for the
  change count's bullet, which is the text bullet U+2022, as the mockup draws it.
  - Where the mockup draws the same thing, its own icon is taken, marked
    "(mockup)". The mockup's search tool draws `text-search`, its terminal tool
    the boxed `square-terminal` and its console tool `message-square-text`, so
    those three follow the mockup's drawing, not the plain `search`, `terminal`
    and `message-square`.
  - Elsewhere the nearest outline icon is taken.
  - Brand and language icons become the nearest generic icon. A header keeps
    `file-code-2` and C# keeps `hash`, so a header still differs from a source
    and a C# file from a C++ one in a tab's title.
  - A row marked "tab title" is a file kind. The lists, the breadcrumb and the
    language servers' settings entries draw that kind as a text badge
    ([0617](0617-draw-file-icons-in-a-colour-by-file-kind-and-folders-in-outline.md)).
    Only a tab's title, which is plain text and cannot hold a badge's box,
    still draws the glyph.

## Rationale

The mockup is drawn in Lucide. Any other set keeps the strokes, corners and
weights of every icon visibly apart from it, however close the shapes. A font
keeps the icons on ImGui's text path, so every place that draws a glyph in a
label, a tab name or a button keeps working unchanged. Reading the offset from
the face's own metrics centres the icons in any face at any size, where a fixed
offset is right at one size only.

## Consequences

### Positive

- Icons match the mockup's shapes and stroke style.
- An icon centres on the text beside it in every face at every scale, within a
  pixel.
- The strong face draws icons, so a bold heading can carry one.
- The generated icon data is 1.3 MB of source instead of 2.7 MB.

### Negative

- Language and brand glyphs are gone. In a tab's title C, C++ and Lua share
  `file-code`, and Markdown shares `file-text` with a read tool, so tabs tell
  them apart only by their names. The lists draw badges, which tell them apart.
- The font's strokes are 2 units of 24, about 1.2 px at 14 px. The mockup draws
  1.75, so the icons are slightly heavier than the mockup's, and a font cannot
  change that.
- Every Lucide glyph in the atlas is as tall as the distance from its top to the
  baseline and as wide as its right edge, whatever it draws. The atlas holds
  empty pixels, and anything that measures an icon by its glyph box gets the
  wrong middle.
- The atlas holds the icons three times, once per face.
- The code face cannot draw `copy`. An icon added later at a Powerline
  codepoint has the same limit there.
- Reading the descent share bakes each face once at 512 px before its merge.
  Only the blank space is loaded, which takes no atlas pixels, and the merge
  discards the bake.
- Updating Lucide means running two scripts with one version, or the constants
  name the wrong icons.

### Neutral

- `IMGUI_USE_WCHAR32` stays. Lucide's codepoints are in the Basic Multilingual
  Plane, but text above U+FFFF still needs 32-bit characters.
- `Core::IconForExtension` follows the same mapping. No Graphite code calls it.

## Alternatives Considered

- **MDI's outline variants.** MDI's outlines are filled shapes with holes, not
  strokes, so they keep the old weight and corners and do not match the mockup.
- **Lucide's SVGs rasterised through FreeType and an SVG renderer.** This gives
  the mockup's 1.75 stroke at any size, but it adds two dependencies and moves
  icons off ImGui's plain text path.
- **A fixed offset per face.** It is right only at the size it was tuned for and
  drifts as soon as a face changes. The share read from the face follows it.
- **The share from ImGui's rounded metrics at the face's own size.** At 15 px
  the rounding puts JetBrains Mono's icons a pixel below its capitals.
